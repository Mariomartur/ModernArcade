# RetroStation app foundation
Objective: make RetroStation an owned application that integrates existing console emulators; first delivery is a runnable, read-only core, not an emulator engine.
Branch: `feat/retrostation-launch-preview` (foundation `6d455df` integrated locally on `main`) · Delivery: `ask-on-risk`, chain `stacked-to-main` (user chose independent main-bound cuts; no PR authorized) · Runner: `TMPDIR=/tmp/opencode python3 -B -m unittest discover -s tests -v` (on Windows use the default temp directory and `python -B`) · First unit: 932 changed lines including the previously untracked canonical master plan; size-exception recommendation remains if preparing a PR.
